# 🔒 Sistema de Autenticação e Perfil Customizável em PHP

Este projeto consiste em um sistema completo de login, gerenciamento de sessões e controle de acesso desenvolvido em PHP para praticar conceitos essenciais de autenticação web e manipulação de sessões.

---

## 🎯 Requisitos da Atividade

Conforme o desafio proposto (`15d_desafio3.md`), o sistema contempla as seguintes funcionalidades:

- 🔑 **Autenticação de Usuário:** Login com validação dos dados cadastrados no banco de dados.
- 🛡️ **Gerenciamento de Sessão:** Controle de acesso seguro utilizando sessões do PHP (`$_SESSION`).
- 👤 **Página de Perfil Protegida:** Acesso restrito apenas a usuários autenticados.
- 🎨 **Personalização do Perfil:** Opção para o usuário escolher e salvar a cor de fundo do seu perfil.
- 🚪 **Logout:** Encerramento seguro da sessão do usuário.
